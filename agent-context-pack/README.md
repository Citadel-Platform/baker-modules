# agent-context-pack

The conventions a coder — or a coding agent working under an operator's
direction — needs before touching a codebase Baker generated.

It is a module rather than a document kept elsewhere, so it is versioned with
the assets it describes, written into the repository by the same `apply` that
writes them, and recorded in `baker.lock.json` beside them. A context pack that
lived outside the catalogue would drift from the modules it explains, and
nothing would say so.

It installs as `AGENTS.md` at the root of the generated repository.
