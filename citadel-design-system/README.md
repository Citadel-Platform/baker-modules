# Citadel design system

Colour, spacing, radius and type tokens, and the primitives built on
them: panels, tables, callouts, status badges, info pills, skeletons and the
failure view.

The failure view matters more than it looks. Every surface that can fail renders
through it rather than printing an exception, so what a person reads when
something breaks is a sentence about their situation instead of a Dart type
name.
